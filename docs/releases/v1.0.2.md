# OfxHost 1.0.2

This release adds a 32-bit float TIFF export, and a RAW file now opens in Linear Rec.709.

## 32-bit float TIFF export

The export dialog offers three bit depths for TIFF: 8-bit, 16-bit, and 32-bit float. The 32-bit option writes IEEE float samples, so the file keeps the values the chain produced, including tones above 1.0. PNG and JPEG XL keep their 8-bit and 16-bit options.

The fourth sample is marked as an unassociated alpha, which a reader now interprets the same way the host does.

OfxHost reads a 32-bit float TIFF back, so an exported file reopens in the host with its color space and its ICC profile.

## Export dialog

The Intent chooser now appears only for the formats that carry a full profile: TIFF, WebP, and JPEG XL. PNG and JPEG keep the stored intent and hide the chooser.

A stored bit depth that the selected format cannot write now snaps back to the nearest depth it can write. This replaces the earlier rule that treated every value at or above 16 as 16.

## RAW opens in Linear Rec.709

A RAW file carries no color tag, so the loader chose the space for it. That space is now Linear Rec.709, which is what the Input Color Space control shows after an open. The control still offers Linear Rec.2020 when the shot needs the wider gamut.

Untagged float TIFF and EXR stay on Linear Rec.2020, because those are scene-linear sources.
