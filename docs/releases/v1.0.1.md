# OfxHost 1.0.1

This release makes a RAW file open about two and a half times faster, and scrolling in the preview now zooms to the cursor.

## Faster RAW open

OfxHost now develops a RAW file in two stages. The first stage bins the sensor data 2x2 and demosaics a quarter of the pixels, so the frame lands sooner. The second stage develops the same file at full resolution and replaces the frame. Export and a 1:1 zoom read the full-resolution frame; while it is still to come, an export says so instead of writing a frame smaller than the file.

Display color conversion now splits its rows across cores, which takes about a quarter of a second off the first frame.

Measured on a 24 MP NEF: 1.3 s to the first frame before, about 0.5 s now.

## Preview zoom

The mouse wheel zooms the preview to the cursor on every platform. It used to pan on macOS. Drag to pan, the horizontal scroll still pans, and a double-click returns to fit.
