# OfxHost 1.0.3

This release fixes a plugin that appeared twice in the Add Plugin list on Windows, and the second copy could not be selected.

## One row per plugin

OfxHost searches the platform OFX directory, every path in `OFX_PLUGIN_PATH`, and its own plugin folder. On Windows the installer of a plugin often sets `OFX_PLUGIN_PATH` to `C:\Program Files\Common Files\OFX\Plugins`, which is also the built-in directory. The host walked that directory twice, loaded the same bundle twice, and listed the plugin twice.

The host now resolves every search path before it walks anything, and it drops a path that another path already covers, because the walk recurses and reaches the same bundle anyway. A directory that is not there is dropped as well, and a path it drops is printed to stderr.

## Selectable rows

The rows of the Add Plugin list took their identity from the plugin label, so two rows with the same label shared one identity and the second row could not be pressed. Each row now has its own identity, which covers two different plugins that carry the same label.
